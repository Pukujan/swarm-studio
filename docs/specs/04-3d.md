# 6. 3D models

## Today

- The game builder has Three.js skills (`gameskills/gamedev/threejs-*`), so it can write 3D games, but only from shapes it draws in code.
- `gltfInfo()` in `engine/appbuild.mjs` reads a `.glb` model's meshes, animations and size, but nothing calls it yet.
- There are no model downloads, no model generation, and no 3D on the canvas or on the designed pages.

## What we build

### 1. Free models (CC0 download)
- **Sources:** Kenney (game kits), Poly Pizza (props, characters) and Poly Haven (realistic models and HDRI lighting). All are CC0, so no credit is required, but we still credit them in `credits.json`.
- **Where models come from:**
  - **The planner:** a page section or a game can ask for `model: "<keywords>"`.
  - **The engine** (`engine/models3d.mjs`): searches the sources, picks the best match by name and polygon count (under 50k triangles), downloads the `.glb`, and keeps it in `runs/<id>/models/`.
- **Size:** each model is capped at 10 MB. Big textures are resized down to 1024 px.

### 2. Generated models (Meshy or Tripo, paid)
- One **hero model** per run, made from the page's generated hero image (image-to-3D), or from text if there is no image.
- **Cost:** it **asks first**. The Auto panel shows "Generate a 3D hero model? Costs ~N credits", and nothing is spent without a yes. It's skipped when there's no key or connector.
- **Timing:** it takes 1–3 minutes and runs alongside the video step, so Auto doesn't slow down.
- **The key:** from a Hermes sign-in connector if one exists, else `MESHY_API_KEY` in `~/.hermes/.env`.

### 3. Where models show up
- **Designed pages:**
  - Sections can use `<model-viewer>` (one script tag, Apache-2.0), with auto-rotate, a scroll-driven turn and a poster image as the fallback.
  - The section gets a `data-model` attribute so the canvas knows about it.
- **Canvas:**
  - A **3D layer**: drop a `.glb` on the canvas, or pick one from the run's models.
  - It renders with `<model-viewer>` and can be orbited, turned and scaled. Its camera angle is saved with the layer.
  - When zoomed out, the snapshot system freezes it like a page, so it saves memory the same way.
- **Games:** the game ask lists the run's models with their `gltfInfo()` (size, animation names), so the builder can load them with Three.js GLTFLoader and scale them correctly.
- **Video:** a 3–4 s turntable shot of the hero model, rendered headless and added to the promo.

## Done when

- [ ] A run with "arcade cabinet" in a section downloads a CC0 model and shows it turning on the page.
- [ ] Dropping a `.glb` on the canvas makes a 3D layer that can be orbited, survives a reload, and freezes when zoomed out.
- [ ] With a Meshy key and a yes, Auto makes one hero model from the hero image and shows it on the home page.
- [ ] Without a key, every 3D step is skipped cleanly and the run still finishes.

## Out of scope

- Rigging, sculpting, editing a model's geometry on the canvas, 3D for whole scenes.
