# ARES credits

- Game: ARES, built for the Nous Hermes hackathon with Swarm Studio for Hermes Agent.
- Hero: Design Bakery, Hermes's swift messenger in winged sandals.
- Bosses: the Nous Hermes hackathon Discord. Every boss is an original stylized character named by Discord handle only (`data/bosses.json`).
