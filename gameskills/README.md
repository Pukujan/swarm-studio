# gameskills

Game-development skills (SKILL.md files) that the Swarm Studio game builder reads before building a browser game, and, for a game made for Godot, Unity or Unreal, before writing that engine's project (`engine/port.mjs`). The engine skills not wired to a port yet (Bevy, Defold, LÖVE, Pygame, Roblox, Ebitengine, the publishing workflows) are here for the next ports.

These files are unmodified copies under their own licences (Apache-2.0 for the gamedev set, and for Open Design; MIT for the upstream of the two Open Design skills). They are not under Swarm Studio's FSL licence. Each source's licence text sits next to the files (`gamedev/LICENSE`, `gamedev/NOTICE`, `opendesign/LICENSE`, `opendesign/<name>/LICENSE.upstream`).
